# 一階 ODE LLM Wiki
本次作業獨立放置於 ode-wiki/，不覆蓋原工程數學專案。
- index.html：Wiki 搜尋與 5 個條目
- slides.html：8 頁教學投影片
- wiki-data.json：查閱五篇來源後，由 LLM 原創中文摘要、公式、例題與來源 URL。
- workflow.js：本次檢查與修正循環，使用 `node workflow.js` 可重跑；網頁由本次實際執行的同一份資料生成，程式本身不會自動查詢 LLM 或外部網站。
- run-log.txt：實際執行的檢查紀錄（含負向測試）

流程：先設定教學對象與範圍 → 查閱五篇資料 → LLM 整理成固定資料結構 → 入庫前檢查 → 依 S01–S05 查詢 → 產生草稿 → 來源/欄位/公式與警語檢查 → 失敗則針對該條目修正（最多 3 次，仍失敗停止）→ 通過才產出 HTML → 檢查連結及部署。資料或來源更新時先重新查證，勿只修改簡報。
